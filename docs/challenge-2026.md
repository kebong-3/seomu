# 2026 공공 AI 대전환 챌린지 · 수정 안내 대응

## 활용성 40
규정·업무 절차 메뉴에서 기관·출처·버전·원문·단계별 할 일/기한/서식/발췌를 등록합니다. 근거 발췌가 원문과 불일치하면 저장할 수 없습니다. 키워드로 상황을 검색하고 처리단계를 확인한 뒤 근거와 기록을 TXT로 저장합니다. 기관 절차 백업은 별도 JSON이며 기존 업무공간 백업과 별개입니다. 문서 검색·AI 초안은 Python 서버가 필요합니다. 모델 검증은 backend의 python -m app.model_eval --live --output 결과.json을 사용합니다.

## 완성도 30
새 환경에서 안내서만 보고 핵심 흐름을 실행합니다. AI 미연결과 실제 생성 결과를 구분하고 실패 시 원문과 사용자 작업을 유지합니다. 개발 자료는 공개·합성 자료만 사용합니다.

## 확산용이성 30
API 키는 서버 환경변수에서만 관리합니다. 기관별 자료·규정·서식을 바꿔 동일 흐름을 재현합니다. 두 모델 실호출은 설정과 권한이 있는 서버에서 수행하고 결과와 미검증 범위를 함께 기록합니다. 자동 테스트나 공급자 이름 선택 기능만으로 2종 실구동을 입증했다고 주장하지 않습니다.
