# 서무 실무 도구 사용 안내

## 첫 사용

1. ‘서무 실무 안내’에서 맡은 업무를 선택합니다. 준비자료·단계별 담당/결과물·예외를 확인합니다.
2. 업무명·기관 기준·마감을 입력하고 취합 양식 XLSX를 받습니다. 입력하지 않은 값은 미확인으로 표시합니다.
3. ‘자료 요청 만들기’로 기존 부서 명단을 연결하거나 ‘업무 체크리스트 등록’으로 개인 일정에 추가합니다.
4. 문서 서버를 연결했다면 ‘내 문서에서 기관 기준 찾기’로 검색 질문을 전달하고 검색을 실행합니다. 이 버튼 자체는 AI 호출이나 외부 전송을 하지 않습니다.

## 여러 파일 취합

1. 결과 열 이름을 쉼표로 적고 필수 열·중복 기준을 고릅니다. 교육 중복이면 대상코드+교육명+이수일 등 여러 열을 선택합니다.
2. XLSX/CSV/TSV 파일을 선택합니다. CSV는 UTF-8 또는 EUC-KR를 읽습니다. 구형 XLS는 Excel에서 XLSX로 저장합니다.
3. 파일마다 ‘제목행’과 열 연결을 확인합니다. 이름/성명 등 명확한 별칭만 제안하며 모호하면 미연결 상태로 남깁니다.
4. 제외할 시트는 ‘이 시트 제외’를 누릅니다. 합계행·설명행도 데이터로 읽힐 수 있으므로 먼저 자료행만 남긴 사본을 권합니다.
5. 미회신 대조는 중복 기준 열을 대상코드 하나로 정하고, 한 줄에 한 코드를 넣습니다. 코드가 없는 행은 다른 사람과 합치지 않습니다.
6. 결과 XLSX는 전체취합·확인필요·미회신후보·검토조건 네 시트입니다. 중복·오류행을 자동 삭제하지 않습니다.

## 초과근무 자료가 두 파일일 때

1. ‘승인·실적 파일 연결’에 승인/명령 자료와 실제 근무자료를 각각 넣습니다.
2. 각각 대상코드·성명·근무일·시각의 열을 연결합니다. 이름만으로는 동일인을 확정하지 않습니다.
3. 한쪽에만 있는 기록은 승인자료 없음/실적자료 없음, 같은 날짜 여러 행은 연결 보류로 표시됩니다. 담당자가 분할근무/정정본 등을 확인합니다.
4. 연결결과 XLSX의 원자료 탭으로 출처를 확인합니다. 매식검토입력 탭에는 연결 오류가 없는 행만 들어갑니다.
5. 매식검토가 필요하면 실제 식사자만 남기고 식사구분·청구액·증빙번호·중복지원·공제분을 채웁니다. 이 시트만 새 파일로 저장해 다음 도구에 넣습니다.

## 초근·매식비 검토

- 한 행 = 한 사람·한 날짜·한 끼. 청구액은 영수증 전체금액이 아니라 해당 사람에게 배분한 금액입니다.
- 기관의 실제 적용 기준과 시행기간·최소 확인시간·1식 한도를 입력합니다. 가상 체험의 120분/9,000원은 실제 지급기준이 아닙니다.
- 시각은 `18:00` 형식. 자정 경과는 `2026-10-02 01:00`처럼 날짜 포함. 시작일은 근무일과 같아야 합니다.
- 대조시간 = 승인구간 ∩ 실제구간의 분 − 입력 공제분. 초과근무수당 인정시간 계산기가 아닙니다.
- 중복지원은 `없음` 또는 `있음`. 빈칸/다른 값은 미확인. 공제 없음은 `0`을 입력합니다.
- 결과는 개인별대조·보완필요·일자별집계·적용기준 네 시트. 일자별 합계에는 중복·문제행도 포함되므로 지급액으로 사용하지 않습니다.
- 승인·실적 매칭으로 식사 제공, 출장비, 휴가, 당직, 증빙 진위가 자동 검증되는 것은 아닙니다. 기관 담당자가 원자료와 대조합니다.

## 보관과 범위

- 새 엑셀 도구의 원본·대조 결과는 브라우저 메모리에서 처리. 메뉴 이동 동안 유지, 새로고침·탭 종료 시 제거. 필요한 결과는 파일로 저장합니다.
- 기존 직원명단·요청·업무체크리스트는 localStorage에 저장. ‘부서 설정’에서 기존 백업 기능 사용.
- 실무 안내의 작성 중 내용은 파일로 저장하세요. 다른 안내를 선택하면 작성내용이 초기화됩니다.
- 원본 파일을 고치거나 업무시스템에 자동 입력·지급·발송하지 않습니다.
- 세부 규정을 추가하려면 기관에서 확인된 원문·버전·출처를 ‘규정·업무 절차’에 등록합니다.

## 개발 검증

```bash
npm ci --prefix frontend
node --test frontend/tests/*.test.mjs
npm run build --prefix frontend
# Playwright와 Chromium이 설치된 환경
node scripts/verify-desk-ui.mjs
```

UI 스크립트는 PLAYWRIGHT_MODULE과 CHROMIUM_PATH 환경변수로 도구 경로를 지정할 수 있습니다. 검증 데이터는 모두 합성자료입니다. 사용 시간 절감의 실측을 의미하지 않습니다.
