## 기존과 달라진 처리

1. 업무명 나열 → 상황 질문, 준비자료, 담당자, 단계별 결과물, 예외, 기관 설정이 있는 16개 실무 흐름.
2. 수동 빈칸 표 → XLSX/CSV/TSV 다중파일·시트 읽기, 제목행 지정, 열 연결, 필수값·중복 후보·미회신 후보와 출처 행 추적.
3. 한 표 수동 대조 → 승인자료와 실적자료를 대상코드·일자로 연결. 같은 날짜 여러 건은 합산하지 않고 보류. 성명 불일치 표시.
4. 인원×단가 → 한 사람·한 끼 단위로 승인/실제 구간의 교집합, 사용자 입력 공제, 최소시간, 적용기간, 식사중복, 증빙 누락, 한도 초과 후보를 검사.
5. 설명에서 종료 → 양식 XLSX, 결과 XLSX(검토조건 포함), 검토서 TXT/인쇄용 HTML, 요청 생성·업무 체크리스트로 연결.
6. 실무 안내에서 등록 문서 검색으로 질문을 전달. 별도 문서 서버/모델 연결이 필요한 기존 AI 구조는 유지하며 연결 없이 AI가 실행된 것처럼 표시하지 않는다.

## 실사용 전 기관에서 채울 자료

- 개인정보를 제거한 기관별 엑셀 원본 1세트(열 제목·시트 형태 유지): 자료취합, 초근 승인, 실제근무, 식사자·증빙.
- 기관의 현행 복무·매식비·여비 지침: 시행일·대상·공제·단가·정산기한. 법정 단가를 앱 기본값으로 추정하지 않는다.
- 현재 XLS는 미지원. 원본 양식의 서식/수식 보존, NEIS/인사랑 직접 연동, 카드 자동 식사자 식별, 자동 지급·공문 발송은 구현하지 않았다.
- 엑셀 도구는 브라우저 메모리 처리. 메뉴 이동 동안 유지, 새로고침/종료 시 제거. 기존 요청·업무·기관절차의 브라우저 저장정책과 구분한다.
- 실무 안내는 작업 절차 참고이며 기관 맞춤 검증 완료 편람이 아니다. 지급·복무의 최종 판단과 기관 지침 확인이 필요하다.
