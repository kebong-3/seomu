## 핵심 반례

1. 같은 사람의 여러 파일을 중복 후보로 표시하면서 행을 삭제하지 않음.
2. 동일한 이름의 열이 여러 개면 자동 매핑 보류.
3. 두 대상 열에 같은 원본 열이 연결되면 취합 중단.
4. 대상코드 없는 승인·실적 행을 서로 연결하지 않음.
5. 같은 날짜 여러 근무 기록이 있으면 첫 행을 임의 채택하지 않음.
6. 자정 경과는 날짜 포함 시각으로만 계산하며 잘못된 날짜·시각 순서 거부.
7. 근무일과 시작일시 불일치, 공제시간 초과, 승인자료 누락을 확인 대상으로 표시.
8. 금액·중복지원 빈칸을 0원/중복 없음으로 간주하지 않음.
9. 적용 기준이나 시행기간이 없으면 정상 판정하지 않음.
10. XLSX 실제 날짜/시간 셀, 수식 거부, 수식처럼 보이는 문자열의 문자열 저장 확인.

## 미검증 범위

실제 기관 서식의 다양한 제목행·합계행·병합 구조 전체, 실제 사용시간 절감, 지급 적정성, 두 AI 모델의 실호출은 이번 검사 범위가 아니다. 모든 시연/검증 자료는 합성자료다. 자동 근태 승인·지급·기관 시스템 연계·직원에게 통지하는 기능은 없다.
