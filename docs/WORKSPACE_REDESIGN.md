# 서무 업무공간 재구성

확인일: 2026-10-10. 중앙기관·지자체의 공개 업무분장과 공개 사례를 선택하여 검토했다. 모든 기관의 비공개 업무를 전수조사한 결과는 아니다. 부서 서무와 운영지원과의 전담 인사·회계·보안 업무를 구분해야 하며, 앱은 자료 취합과 확인을 보조한다.

- [국립축산과학원 운영지원과 업무분장](https://www.nias.go.kr/front/soboarddown.do?boardSeqNum=294&cmCode=M160721184807976&fileSeqNum=295): 인사·보안·교육·복무·관인·당직·비상연락망·기록물·정보공개·후생복지·감사·경비·물품을 참고했다. 과거 분장 자료이며 현재 담당자나 현재 규정의 근거로 사용하지 않는다.
- [국립보건연구원 담당업무](https://www.nih.go.kr/ko/singl/organ/list.do?menuNo=300247&orgCd=1790526&pageIndex=1): 성과관리와 인사(복무·상훈·겸직), 제증명·신분증 등의 범위를 확인했다.
- [군산시 서무실록](https://officemanager.oopy.io/): 회계·출장·감사 및 법령·복무·정보공개·공문서·권한신청·SW 자동화 등 실제 공개 메뉴를 확인했다. 처리순서·서식·근거 접근이라는 구성을 참고했다.
- [인사혁신처 서유기 발표](https://www.mpm.go.kr/mpm/comm/newsPress/newsPressRelease/?boardId=bbs_0000000000000029&category=&cntId=4313&mode=view&pageIdx=3): 서무 반복 입력을 줄이고 출장자가 직접 처리하는 방향을 참고했다. 이번 앱의 직원 직접 제출은 공유 서비스로 완성되지 않았다.

## 구현과 후속 범위

| 기능 | 이번 구현 | 후속 범위 |
|---|---|---|
| 첫 화면 | 로그인 없이 오늘·메뉴·업무 도구 | 조직별 로그인·SSO |
| 요청·취합 | 직원 등록, 대상·기한·항목 지정, 제출 입력, 빈칸 검사, 보완·확인 상태, 요청문·CSV 출력 | 직원 공유 링크·알림·XLSX·서버 저장 |
| 공문 연결 | 인식 결과의 문서명·경로·버전을 요청에 전달 | AI 대상·항목 자동 제안과 승인 흐름 |
| 교육 | 교육자료 요청·수료증 자료명·검토 상태 | 파일 증빙 검수·시간 인정 규칙 |
| 정산 | 사용자 입력 단가로 계산·계산식 출력 | 기관별 최신 여비 규칙·예외·지급 연계 |
| 반복 업무 | 기한·담당·체크리스트·다음 회차 생성 | 자동 알림·공유 캘린더 |
| 보관 | 브라우저 localStorage, JSON 백업·추가 복원 | 역할별 접근권한·공유 DB·감사 이력 |
| 문서 인식 | 기존 Python 서버의 파일·폴더·ZIP·추출·OCR·검색·원문 확인 유지 | 새로운 OCR 모델 품질 비교·배포 검증 |

주민등록번호·건강정보·급여 명세 등 민감자료를 브라우저 업무공간에 수집하도록 설계하지 않았다. 문서 키 인증을 제거하지 않았으며, 원본 접근은 기존 서버 인증을 유지한다.

## GitHub·Hugging Face 참고 확인

- [Docling](https://github.com/docling-project/docling): 문서 구조화와 추출기의 선택 연결을 검토. 기존 선택 모듈을 유지하며 새 모델 실행·품질 개선을 주장하지 않는다.
- [SmolDocling Space](https://huggingface.co/spaces/docling-project/SmolDocling-256M-Demo): 공개 데모 존재를 확인. 모델을 탑재하거나 기관 문서를 전송하지 않았다.
- [PaddleOCR-VL Space](https://huggingface.co/spaces/PaddlePaddle/PaddleOCR-VL_Online_Demo): 공개 시연 페이지를 확인. 한국어 성능 비교·모델 설치는 미실시.
- [RAGFlow](https://github.com/infiniflow/ragflow): 구조화 문서·검색 업무공간을 검토. 원문 위치·인식 상태를 확인하는 기존 문서함을 유지했다.

위 검색은 대표 공개 사례 검토다. 모든 GitHub 저장소·Hugging Face Space·PAX 사례를 전수검색했다고 표시하지 않는다. 군산 gongedu·완주소방 장비서무의 세부 기능은 이번 조사에서 원문을 새로 확인하지 않았으므로 구현 근거로 단정하지 않았다.

## 검증

- TypeScript 타입 검사와 Vite 프로덕션 빌드.
- API 정상 JSON·HTML 404·HTML fallback·네트워크 실패·401 회귀 검사.
- 손상 저장값·잘못된 백업·체크리스트 구조·CSV 수식문자·빈 제출항목 회귀 검사.
- 브라우저에서 로그인 없는 첫 화면, 직원 등록, 교육 요청, 빈칸 승인 차단, 제출·확인 완료, 새로고침 후 보존 확인.

새 서버·기관 인증·OCR 모델을 배포하거나 직원 간 공유를 검증한 결과는 아니다.
